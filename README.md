# 법인카드 집근처 사용 분석

1. 카카오 개발자 콘솔에서 JavaScript 키 발급, 사이트 도메인에 `http://localhost:5500` 등록, 카카오맵 사용 설정 ON
2. `start.bat` 실행(PowerShell 내장 서버, 별도 설치 불필요) → 브라우저에서 ① 설정에 키 입력
3. ② 카드내역(xlsx/csv) 업로드 → ③ 직원 집주소 등록 → ④ 분석 실행
4. 샘플: ② 화면의 "샘플 데이터로 체험하기" (`sample/` 폴더)

카드 컬럼: 순번, 카드번호, 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소, 사업자 등록번호, 승인번호, 과세유형, 전표구분, 미화금액, 미화환율, 승인시간, 가맹점업종코드, 가맹점업종명, 유종, 리터당단가
(필수: 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소)
