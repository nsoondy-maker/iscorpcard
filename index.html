법인카드 집근처 사용 분석

카카오 지도 설정

1) developers.kakao.com에서 앱 생성 → JavaScript 키 복사
2) JavaScript SDK 도메인에 이 페이지 주소(예: http://localhost:5500) 등록
3) 카카오맵 사용 설정 ON. file://로 열면 동작하지 않으니 start.bat으로 실행하세요.

분석 기준

위험점수: 집근처 40 + 휴일 20 + 심야 15 + 주의업종 25 (60점 이상 높음, 40점 이상 주의)

경영진 보고서 (Gemini)

전송 내용: 집계 지표와 이상징후 상위 거래(가맹점명·일자·금액·사유·거리). 카드번호와 집주소는 전송하지 않습니다. API Key는 이 브라우저에만 저장됩니다.

개인정보 안내

카드내역·집주소는 이 브라우저 안에서만 처리됩니다(서버 전송 없음). 주소 검색 시에만 주소 문자열이 카카오 API로 전달됩니다. 집주소와 지오코딩 캐시는 브라우저 localStorage에 저장되므로 공용 PC에서는 사용 후 아래 버튼으로 삭제하세요.

법인카드 내역 업로드

엑셀(.xlsx/.xls) 또는 CSV 파일을 끌어놓거나 클릭해서 선택

필수 컬럼: 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소. 그 외 컬럼(순번, 카드번호, 승인시간, 가맹점업종명, 유종 등)은 있으면 활용합니다. 샘플 데이터로 체험하기
